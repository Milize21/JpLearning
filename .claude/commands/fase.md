2. Baca brief fase induknya di `docs/08-roadmap-fase.md` (mis. 0.1 → bagian Fase 0) dan semua dokumen di "Baca dulu". Baca selektif sesuai peta dokumen di `AGENTS.md` §2.

6. **BERHENTI.** Jangan membuat atau mengubah file apa pun sebelum pemilik proyek menyetujui rencana.
